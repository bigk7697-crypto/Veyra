Intégration · 5 min

3 ÉTAPES

Widget côté client, enroll côté serveur, décision via l'API.

web.html
<script src="https://votre-domaine/widget.js"></script>
<div id="security-check"></div>
<script>
Veyra.challenge({
  container: "#security-check",
  apiBase: "https://votre-domaine",
  userId: "alice",
  onSuccess: (r) => console.log(r.sessionId),
  onFailure: (r) => console.log(r.next_action)
});
</script>
api · REST
POST /v1/enroll        { userId, secretWord, color, motif }
POST /v1/challenges    { userId } → { id, grid, ttlSeconds }
POST /v1/challenges/:id/verify
  → { verified, risk_score, risk_level, next_action }
  • 1Enroll une fois par utilisateur. Secret hashé scrypt, jamais en clair.
  • 2Le widget affiche une grille unique à chaque challenge.
  • 3Votre backend applique next_action : none · retry · require_mfa.

Challenge dynamique

Positions, couleurs, distracteurs et motifs mélangés. Jamais deux fois pareil.

Secret personnalisé

Couleur + motif + mot secret. Stockage scrypt et AES-256-GCM.

Risk Engine

Temps, intervalles, corrections, essais. Un signal, pas une sentence.

Clés & dashboard

Clés révocables, stats et événements temps réel.
