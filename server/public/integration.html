GUIDE · 5 MINUTES

Intégrez Veyra à votre projet

Quatre étapes. Le secret ne touche jamais le frontend — les challenges sont créés et vérifiés côté serveur.

1

Enroller l'utilisateur — une fois, côté serveur

bash
curl -s -X POST https://votre-domaine/v1/enroll \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $VEYRA_KEY" \
  -d '{"userId":"alice","secretWord":"TIGRE","color":"violet","motif":"etoile"}'
2

Créer le challenge — côté serveur, à chaque vérification

bash
curl -s -X POST https://votre-domaine/v1/challenges \
  -H "Content-Type: application/json" \
  -H "X-API-Key: $VEYRA_KEY" \
  -d '{"userId":"alice"}'
# → { id, grid, ttlSeconds, expiresAt, instruction }
3

Afficher le widget — avec le challenge du backend

web.html
<script src="https://votre-domaine/widget.js"></script>
<div id="security-check"></div>
<script>
Veyra.mount({
  container: "#security-check",
  apiBase: "https://votre-domaine",
  challenge: CHALLENGE_JSON_FROM_YOUR_BACKEND,
  onSuccess: (r) => fetch("/api/login", {
    method: "POST",
    headers: {"Content-Type": "application/json"},
    body: JSON.stringify({ user: "alice", veyraSession: r.sessionId })
  }),
  onFailure: (r) => console.log(r.next_action) // retry | require_mfa
});
</script>
4

Vérifier la session — côté serveur, jamais le frontend seul

node · sdk/veyra.mjs
import { createClient, requireVeyraSession } from "./sdk/veyra.mjs";
const veyra = createClient({ baseUrl: process.env.VEYRA_URL, apiKey: process.env.VEYRA_KEY });

const decision = await requireVeyraSession(veyra, sessionId);
if (!decision.verified) throw new Error("accès refusé");
if (decision.next_action === "require_mfa") { /* votre MFA */ }

Le risk_score est un signal, pas une preuve : logguez-le, ne bannissez pas dessus. Règles : none → continuer, retry → nouvel essai, require_mfa → votre MFA.
